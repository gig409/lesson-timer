# Lesson Timer

Classroom countdown with Start / Pause / Reset, for embedding in slides.com or reveal.js via an iframe.

URL options: `m` (minutes), `s` (seconds), `label`, `theme=dark|clear`, `end=0` (end alarm off), `ticks=0` (final-seconds countdown beeps off), `tickfrom=15` (when the countdown beeps start), `auto=1`, `compact=1` (always icon-only buttons; otherwise they switch automatically when the timer is small).

On-screen switches toggle the end alarm and the final-seconds countdown beeps during a lesson.

Example: `https://gig409.github.io/lesson-timer/?m=4&label=Do%20Now`
