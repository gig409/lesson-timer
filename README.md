# Lesson Timer

Classroom countdown with Start / Pause / Reset, for embedding in slides.com or reveal.js via an iframe.

URL options: `m` (minutes), `s` (seconds), `label`, `theme=dark|clear`, `end=0` (end alarm off), `ticks=0` (final-seconds ticking off), `tickfrom=30` (when ticking starts), `auto=1`.

On-screen switches toggle the end alarm and the speeding-up ticks during a lesson.

Example: `https://gig409.github.io/lesson-timer/?m=4&label=Do%20Now`
